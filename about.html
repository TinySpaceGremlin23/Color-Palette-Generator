Hey, look. Another color generator thing.
I'm not the best at explaining things, but the palettes are
made using the position of the letters of whatever
the input is, ASCII Codes and some math.

You start with the ASCII value of the letter.
Here's an entire guide for that,
all the way down to the chart.

After that, you add that number to the number the letter's position
is (the "name.length" in the JS.) The "index" always starts at 0, so in the
video, the position of "C" is 0. You then multiply that
by 72, the number I set to gives the palettes some range.

Then you get your "seed", which you then do the math
with the multipliers (123,456,789). The % is modulus, or
"what remains after perfect divison".
256 is the number of shades for the RGB channels.
